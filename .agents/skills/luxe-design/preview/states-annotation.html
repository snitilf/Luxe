Upstream used one ring for annotation and focus, on the argument that both mean attention is here. This system splits them, because they mean different things to different actors: the gold outline is a durable mark the user made and the agent will receive, while the focus ring is transient keyboard position. Once a session ends the annotation hue is removed entirely and outlines drop to the emphasis border, so nothing on a dead session still looks actionable.

An outline follows the element's own border radius, and there is no radius property for outlines, so an annotation never forces geometry onto the artifact it is marking. The stroke width and offset are fixed; everything else is inherited from whatever was clicked.
