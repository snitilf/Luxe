A queued prompt is unsent, so it is drawn as an outline: dashed emphasis border on the canvas, with a clock glyph. It goes solid on the top plane only while a send is in flight, which is the one moment a prompt is sent but not yet cleared - a successfully sent prompt is removed, not restyled. The close control is a round icon button with a stroke cross, never a text glyph: font metrics put a text cross off centre even under flex centring.
