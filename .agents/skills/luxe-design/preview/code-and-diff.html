Code sits on its own recessed plane - --code-bg is darker than the canvas, not lighter - inside a --strong border, set in the mono at label size. The syntax inks are shipped as a bespoke theme rather than a borrowed one, and every one of them is a dark, so they all survive on both diff tints. Punctuation is the single decoration-grade ink in the set. The hunk-header tint has no equivalent key in a theme file and is applied by the surrounding component instead.
