Annotate Reload artifact Status banner icon

Words first, icons second. Icons are inline stroke SVG on a 24 viewBox, drawn at --icon-nav in the toolbar and --icon-card in cards and status banners, stroke --stroke-icon, round caps and joins, always currentColor so they tint with their label. No icon font, no sprite sheet, no CDN: the tool has to work offline. Never fill an icon sitting beside control-size text, and never use an emoji as an icon. Status is icon plus text label, never colour alone.
