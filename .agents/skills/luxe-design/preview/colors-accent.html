The one accent
An annotated element
A sentence with a selected range inside it.
--gold --gold-wash --focus-ring

One hue, one meaning: attention is here. The gold is the element outline and the selected-text wash, and nothing else. It is not a chart colour, not a shape colour in a diagram, not a button, not a link, and not the focus ring. The focus ring is the info slate, so that a focused control and an annotated element never look like the same event. This is the system's single exception to neutral-first, and it exists because a grey outline is invisible against a hairline border.
